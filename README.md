# homebrew-nord-docker-proxy

Homebrew tap for [nord-docker-proxy](https://github.com/taylorbird/nord-docker-proxy):
NordLayer in Docker, exposed to your Mac as a local SOCKS5 proxy.

```sh
brew install --cask taylorbird/nord-docker-proxy/nord-docker-proxy
nord-docker-proxy setup
```

The cask's version and sha256 are bumped by the app repo's `scripts/release.sh`.
